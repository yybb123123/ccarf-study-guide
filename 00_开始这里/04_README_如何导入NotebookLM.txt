# 这个 ZIP 包如何使用

建议：NotebookLM 笔记本命名为 Anthropic CCAR-F — Exam Preparation。

第一步：从 Anthropic 官方地址单独保存 Exam Guide v1.1 PDF：
https://cc.sj-cdn.net/instructor/6nizmqk8tpzpfjvt6qmmav7rh/public/1794946250/Claude_Certified_Architect_-_Foundations_Exam_Guide.pdf

第二步：在 NotebookLM → 添加来源 → 上传文件，上传该官方 PDF。

第三步：将本 ZIP 解压，把 01、02、03、04 文件也上传到同一笔记本（README/05 仅供查看）。

第四步：在 NotebookLM → 添加来源 → 网站，依照 05 文件选择并逐个添加真实的官方网页。

第五步：打开 04 文件，复制提示词发到 NotebookLM 对话。

注意：本 ZIP 不是 Anthropic 官方考试资料的完整镜像；包含本人编写的考纲导航与练习辅助材料，官方考试 PDF 和课程原始内容均应直接从出版方获取。Academy 需要登录的课时不能通过贴网址自动获取。
