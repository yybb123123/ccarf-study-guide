# CCAR-F 学习指导台

> Claude Certified Architect – Foundations（CCAR-F）备考工作台：**14 天可勾选计划 + 31 份资料地图 + AI 导师 + 进度云同步**。
> 单文件、零依赖、不联网也能用（AI 与同步功能除外）。

## 在线使用

打开 <https://yybb123123.github.io/ccarf-study-guide/>

> 在线版已包含全部 31 份 PDF 与 7 份文本，点资料名即可直接在浏览器打开。

## 本地使用

把整个文件夹拷到本机，双击 `index.html`（或改名为 `学习指导.html`）即可；
勾选进度、写笔记都会自动存在浏览器本地（localStorage）。

## AI 导师（可选）

1. 点右上角齿轮 → 填入 Anthropic API Key（`sk-ant-…`）；
2. 点「获取列表」自动拉取可用模型，或手填模型名；
3. 保存后即可在「AI 导师」区块对话：它带着你当前的勾选进度和最近 5 条笔记当上下文。

也支持 OpenAI 兼容接口（填 Base URL + 模型名），但对方服务必须允许浏览器跨域访问。

**Key 只存在你自己的浏览器里**，不会写进仓库，也不会经过任何第三方服务器。

## 进度云同步（可选）

在设置里填一枚只有 `gist` 权限的 GitHub Token，留空 Gist ID 会自动新建一个私密 Gist 存进度。
换电脑打开同一页，勾选「自动同步」就能接着学。
