# CCAR-F 学习指导台

> Claude Certified Architect – Foundations（CCAR-F）备考工作台：**15 个单元的可勾选计划 + 39 份资料地图 + 本地知识库 + DeepSeek 费曼导师 + 客观错题复习**。
> 静态托管、无后端；学习数据只保存在本机浏览器，AI 功能需联网并自备 API Key。

## 在线使用

打开 <https://yybb123123.github.io/ccarf-study-guide/>

页面包含全部 39 份学习资料的浏览入口；中文优先，英文原名保留。

## 数据在哪里

| 数据 | 存储 |
| --- | --- |
| 学习进度、笔记、实作验收、错题、掌握状态、费曼对话 | `localStorage` |
| 导入的知识库资料与检索片段 | IndexedDB `ccarf-kb` |
| 完整备份 | 「数据」面板导出 JSON（v2，带 SHA-256 校验） |

- 备份**不包含** API Key 或 Token。
- 换浏览器或清空站点数据前，先导出备份。
- 个人笔记、译文与错题不要提交到公开仓库。

## AI 导师（可选）

1. 右上角齿轮 → 选择服务商（默认 DeepSeek）；
2. 填入自己的 API Key（形如 `sk-…`）；
3. 保存后即可在「导师」面板做费曼五步与题目解析。

也支持任意 OpenAI 兼容接口（填 Base URL + 模型名），对方服务必须允许浏览器跨域访问。
Key 只存在你自己的浏览器里，不写进仓库，也不会经过第三方服务器。

## 本地知识库

- 支持 Markdown、TXT、可提取文本的 PDF；
- 资料只写入本机 IndexedDB，用 SHA-256 去重；
- 检索使用 BM25（中英文），回答只发送最多 4 个片段给当前 AI 服务商；
- 扫描件不做 OCR，会明确标为「无文本」。

## 官方考纲与掌握追踪

- 基准：`01_官方考纲_必读_最优先/00_CCAR-F_Exam_Guide_v1.1_官方42页.pdf`（v1.1，2026 年 11 月生效）；
- 结构化目标：`data/exam-objectives.json`，含 5 个领域、30 条 Task Statement、6 个情景与考试格式；
- 课程映射：`data/curriculum-map.json`，15 个单元与 39 份资料按领域映射到 TS，资料范围标注为考纲内 / 官方相关 / 考纲外 / 未验证；
- 「考纲目标」页面可查看官方原文、中文提示（非官方）、相关单元与资料、练习证据；
- 掌握判定需要客观证据：至少 4 次作答、3 次正确、3 道不同题、2 个不同日期、正确率 ≥75%；
- 中文提示与 AI 补充均标注为非官方；页面不是官方材料，以官方 PDF 为准。

## 情景训练与模拟考场

- 六个官方情景（Customer Support、Code Generation、Multi-Agent Research、Developer Productivity、CI、Structured Data Extraction），每个可练 Level 1 基本理解 / Level 2 架构决策 / Level 3 条件变化；
- 题库：`data/question-bank.json`，60 道原创模拟题（每条官方 Task Statement 2 道），均带逐项解析并标注「非官方真题」；
- 完整模拟要求已验证题库 ≥60 且均有官方依据；当前 60/60，已开放 60 题 / 120 分钟模式。不足时按钮会自动禁用，不把不完整测验标记为正式通过；
- 专项测验支持计时、题号导航、标记复查、自动保存、刷新续考、超时自动交卷、按领域/TS 报告、错题自动进入复习；
- 报告只做本站学习指标；720 分是官方评分规则说明，不做官方分数预测。

## 学习工作台

六个核心入口：今日学习、考纲目标、情景训练、模拟考场、错题复习、资料与工具（知识库 / AI 导师 / 数据管理）。

- 今日学习：当前单元、对应 Task Statement、必读资料、NotebookLM 推荐、待复习、最近模拟、考试就绪度；
- 就绪度是本站内部指标（已验证目标、领域分布、待复习、最近模拟），不是官方通过概率；
- 目标考试日期只存本机，用于显示剩余天数；
- 阅读顺序：中文标题优先、英文术语保留、原始文件名次要；官方中文网页与英文 PDF 可能版本不同；
- AI 学习入口：费曼教学在「资料与工具 → AI 导师」，自由问答在页面 AI 导师区块，两者共享同一份 API 配置。

## 工程与测试

```bash
node --test tests/*.test.mjs   # 单元测试
bash scripts/verify.sh --full  # 站点检查 + 测试
```

- `index.html`：单文件页面，内联 core（纯逻辑）与 studio（本地工作台）；
- `scripts/check-site.mjs`：结构、本地链接、内联 JS 语法；
- `tests/`：迁移、检索、SRS、备份、题目 Schema、导师请求等；
- GitHub Actions 对每个 PR 运行 `verify`，main 受分支保护。
